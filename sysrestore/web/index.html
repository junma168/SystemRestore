这个软件是做什么的？（点击展开 / 收起）

系统复原工具：重装系统之前，它把本机已安装的软件和编程环境（Git / Node / Python / Java / VS Code…）扫描成一份清单； 重装系统之后，只需安装本工具 → 打开清单 → 点击「一键安装」，即可按清单复原原系统的软件和环境，不必再逐个回忆、逐个下载。

清单完全由您自己决定：每个条目都可以删除（选中行 → 点「删除选中」）、编辑（双击行，可改安装方式/版本/直链）、 新增（点「＋ 新增条目」手工补充扫描漏掉的软件）；第一列的勾选框决定该条目是否参与恢复——不勾选就不会安装，取消勾选即可，无需删除。

系统自带的内容（Edge、OneDrive、Windows 内置应用等，新系统装完就有）扫描时已自动排除，不会出现在清单里； 如确需保留某类系统组件，可在「① 扫描系统」取消勾选「排除系统自带组件」后重新扫描。

用完后请点页面右上角「退出工具」按钮退出——直接关闭浏览器标签页不会结束后台进程。

重装系统后：打开本工具 → 打开清单文件(.json) → 切到「一键安装」。清单文件与同目录下的 configs 文件夹要一起拷贝，否则配置文件无法恢复。

双击行可编辑；右键可打开下载页面

重装系统后：打开清单，点击「开始一键安装」

安装前会自动比对新系统现状：已经装过的软件不会重复安装。安装按 运行库 → 开发工具 → 应用 → 商店 → WSL → npm → pip → 配置 的顺序自动进行； 安装结束后会自动配置环境变量（把 Node / Python / Java / Go / Git 等目录补进用户 PATH、设置 JAVA_HOME，无需手动设置）；单项失败不影响其余，结束后生成安装报告。

使用说明

重装系统前（在旧系统上操作）：
1. 进入「① 扫描系统」，勾选要扫描的内容，选择清单保存位置，点击「开始扫描」；
2. 扫描完成后，把生成的清单文件夹整个拷贝到 U 盘或网盘（manifest.json 和 configs 文件夹要在一起）。

重装系统后（在新系统上操作）：
1. 打开本工具，进入「② 安装清单」，点击「打开清单」选择 manifest.json；
2. 按需勾选/取消条目，也可以新增、编辑、删除；
3. 进入「③ 一键安装」，点击「开始一键安装」，等待完成。
建议以管理员身份运行（打包版右键 exe → 以管理员身份运行），否则很多软件装不上。

安装方式说明：
· winget / 商店：自动安装，优先使用；
· Chocolatey / Scoop：本机装有对应包管理器时可用；
· npm -g / pip：恢复 Node/Python 全局包（需先装好 Node/Python）；
· WSL：重新安装原发行版（可能需要重启）；
· 直链静默安装：需填写安装包直链和静默参数；
· 手动安装：无法自动处理的会标「需手动」，请按备注手动安装，也可双击条目补上直链。

本地安装包（有下载好的安装包时用它）：
重装前把下载好的 .exe/.msi 安装包放进「① 扫描系统」里的本地安装包目录（默认 桌面\SystemRestore\packages），扫描时会自动做两件事： 能按名称匹配上已有软件的，给该条目打上 📦 标记——安装时优先运行本地文件，不联网、不依赖 winget 源，本地文件找不到才回退原安装方式； 匹配不上的安装包会单独成为「本地安装包」条目。也可以在「② 安装清单」双击任意条目，把安装方式改成「本地安装包」并点「浏览…」逐个指定。 .msi 自动走 msiexec 静默安装；.exe 默认加 /S 静默参数（NSIS 通用），个别安装器不识别时可在条目编辑的「静默参数」里改。

系统自带组件会自动排除：
Edge、OneDrive 以及 Windows 内置应用（照片、计算器、邮件、终端、Xbox 等）在新系统装完后就有，扫描时默认不记入清单 （Edge WebView2 运行时例外，很多应用依赖它，会保留）。如确需保留某类系统组件，在「① 扫描系统」取消勾选「排除系统自带组件」后重新扫描即可。

安装前自动比对新系统：
点「开始一键安装」前，工具会先检测新系统里已经有什么——已安装的软件（版本相符）不会重复安装，安装表中「系统现状」列会标注每一项是「✔ 已存在」还是「未安装」。 也可以随时点「检测系统现状」单独预览；确需重装某个已存在的软件，勾选「强制重装」即可。

用途说明：
扫描时会自动为每个条目生成一句中文说明（这个软件/环境是做什么用的），显示在条目名称下方——时间久了不记得某个软件是干嘛用的，看一眼就知道。 说明由内置的常见软件库自动匹配生成，双击条目即可修改；识别不出的条目只按类别给通用说明，也欢迎自己补上。

怎么退出工具：
本工具的界面就是浏览器页面，exe 本身是后台进程——直接关闭浏览器标签页不会退出工具，进程还会在后台运行。 请点页面右上角的「退出工具」按钮彻底退出（会同时结束后台进程）；直接关标签页时浏览器也会弹确认框提醒您。 另外，关闭启动时的黑色命令行窗口、或按 Ctrl+C，同样可以退出。

环境变量自动配置：
很多开发环境（Node / Python / Java / Go / Git…）装好后还要配 PATH 才能在任何目录使用。本工具在安装结束后会自动把它们的目录补进当前用户的 PATH、 自动设置 JAVA_HOME 等环境变量（只增不删，仅写入当前用户，不影响系统级设置），对新打开的终端 / 程序生效。 如果之后仍发现某命令不能用，点「③ 一键安装」页的「补齐环境变量」即可手动补一次（会同时应用清单里记录的原系统 PATH 快照）。

小贴士：
· winget 没有收录的软件会标记为「手动安装」；
· pip/npm 条目默认全选，恢复时间较长，可按需取消；
· 「补齐环境变量」只做「只增不删」的补齐，不会删除您现有的 PATH 条目。
